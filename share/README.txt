CBD Share trial package

Mac:
1. Install Node.js 18 or newer from https://nodejs.org/.
2. Open Terminal, enter the package folder, and run: chmod +x start-share.command
3. Double-click start-share.command, or run: ./start-share.command
4. On the host computer open http://127.0.0.1:4173/?v=21
5. Friends on the same Wi-Fi can open http://YOUR-LAN-IP:4173/?v=21
6. Admin page: http://YOUR-LAN-IP:4173/admin.html

Windows:
1. Install Node.js 18 or newer.
2. Double-click start-share.bat.

The store folder contains local submissions and profiles. Keep it with the site.
This package is intended for private trial use. It has no login or public internet security layer.
